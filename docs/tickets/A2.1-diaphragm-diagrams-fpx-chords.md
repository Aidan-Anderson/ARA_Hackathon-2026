# A2.1 — Diaphragm diagrams, F_px, Chords

- **Track:** A (Hamid)
- **Phase:** A2 (12:30–1:15)
- **Type:** AFK
- **Blocked by:** A1.1

## What to build

1. **F_px** for each Level ([spec §5.4](../spec.md#54-f_px-seismic-only)):
   - raw = (ΣF_i / Σw_i) · w_x over this Level and every Level above it
   - min and max bounds; `fpx` = raw clamped to them
   - `design` = max(F_x, fpx); `governs` is the term that won
2. **F_px run:** load w(s) = q_px · depth, where q_px = design / netArea.
   - Gives `reactionFpx`.
   - `SpanResult` diagrams: shear, moment, unitShear (net depth), chord (gross depth), with exact maxima ([spec §5.5–5.6](../spec.md#56-diaphragm-reactions-unit-shear-chords)).
   - Drawing stations at most 1 ft apart.
   - `unitShearLeft` / `unitShearRight` on each line.
3. **Results panel:**
   - Add the F_px columns (raw / min / max / design / governs) to the Level forces table.
   - Add a **Diaphragm Spans** table: from→to, L, max V, max v, max M, max Chord.
