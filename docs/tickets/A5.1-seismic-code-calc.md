# A5.1 — Seismic code calc + USGS lookup

- **Track:** A (Hamid)
- **Phase:** A5 (2:45–3:30)
- **Type:** AFK
- **Blocked by:** A4.1

## What to build

1. **`engine/seismicCode.ts`:** pure functions ([spec §5.14](../spec.md#514-seismic-code-calc-phase-a5); research §3, B1–B6):
   - `periodTa`, `cs` (with the upper and lower limits), `baseShear`, `verticalDistribution` (with k)
   - `calcStoryForcePsf(project)` returns the new `fxPsf` for each Level
2. **`usgsLookup(lat, lon, riskCategory, siteClass)`:**
   - `fetch` to the ASCE 7-22 endpoint with a 10 s timeout.
   - Returns `{ sds, sd1, s1, sdc, tl }` or a readable error.
3. **§12.3.3.4:** if `sdc` is D, E, or F and the outline has a notch wider than 0.15 × the plan width **and** deeper than 0.15 × the plan depth:
   - multiply that Level's Collector and transfer Collector Demands by 1.25 for SX and SY
   - raise the `reentrant-irregularity` warning
4. **`ui/panels/SeismicCodePanel.tsx`** ("Code calc" tab):
   - **Inputs:** lat/long, risk category, site class, S_D1, S1, T_L, SDC, R, C_t, x. S_DS and I_e are shared with `loads`.
   - **"Look up from site"** button: fills S_DS, S_D1, S1, SDC, T_L.
   - **"Calculate F_x"** button: writes `fxPsf` into every Level and shows T, C_s, V, k, and F_x for each Level.
