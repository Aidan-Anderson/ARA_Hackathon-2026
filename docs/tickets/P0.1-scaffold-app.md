# P0.1 — Scaffold the app

- **Track:** both (one person drives, about 15 min)
- **Phase:** 0 (11:00–11:45)
- **Type:** AFK
- **Blocked by:** —
- **Needs:** Node 20+

## What to build

1. **Vite app:** create a Vite React + TypeScript app in the repo root, keeping the existing `problem.md`, `GLOSSARY.md`, and `docs/`:
   `npm create vite@latest . -- --template react-ts`. If it refuses a non-empty folder, scaffold in a temp folder and copy the files in.
2. **Vitest:** `npm i -D vitest`. Add the scripts `"test": "vitest run"` and `"test:watch": "vitest"`, and one trivial passing test.
3. **Folders:** create the structure from [spec §4.1](../spec.md#41-stack-folders-ownership), with a placeholder file where a folder would otherwise be empty.
4. **`.gitignore`:** `node_modules`, `dist`.
5. **`README.md`:** one paragraph on what the app is; `npm install`, `npm run dev`, `npm test`; links to `problem.md`, `docs/spec.md`, `GLOSSARY.md`, `docs/tickets/`.
6. **`CLAUDE.md`:** short rules for agents working in this repo:
   - Read `GLOSSARY.md` and `docs/spec.md` before coding.
   - Use Glossary terms in code: `ShearLine`, `LateralElement`, `DiaphragmSpan`, `Collector`, `Chord`, `Level`, `Story`, `Opening`, `TransferForce`. Never use "tributary" for reactions.
   - `src/engine/` is pure TypeScript: no React, no DOM, no `fetch` except in `seismicCode.ts`.
   - Units: ft, kips, kip-ft inside the engine. Convert psf and plf at the boundary.
   - Test the engine through `analyze()` with the fixtures in `src/model/fixtures/`.
   - `src/model/` is shared between the two tracks. Don't change it without saying so in the commit message.
   - If docs disagree: `problem.md` > `docs/spec.md` > research.
7. **Commit and branches:** commit to `main`, push, then create `track-a` and `track-b` from `main`. (P0.2 can be done on `main` first.)

## Acceptance criteria

- [ ] `npm run dev` serves the app
- [ ] `npm test` passes
- [ ] The folder structure matches spec §4.1
- [ ] `README.md` and `CLAUDE.md` are committed and pushed to `main`
