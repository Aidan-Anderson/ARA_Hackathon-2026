# A1.1 — Diaphragm Reactions on one rectangular Level

- **Track:** A (Hamid)
- **Phase:** A1 (11:45–12:30)
- **Type:** AFK
- **Blocked by:** P0.2

The walking skeleton for the engine: from F_x to a Diaphragm Reaction on each
Shear Line, shown in the Results panel.

## What to build

1. **`engine/beam.ts`:** simple-beam statics for one span with **piecewise-uniform loads plus point loads** ([spec §5.5](../spec.md#55-diaphragm-spans-and-overhangs-simple-beams)).
   - Returns the end reactions and the V and M diagrams.
   - Write it in full generality now; A2.x and A4.1 reuse it.
   - Unit-test it on its own. A uniform load gives wL/2. The ADR example (two load pieces) gives 13.125 / 9.375.
2. **`engine/analyze.ts`:**
   - For each Level, independently (no story shear yet), and for SX and SY:
     - Sort the Shear Lines in the load direction.
     - Load w(s) = q_x · depth, using `crossSection` for the depth. Assume a rectangle with no Openings for now.
     - Compute the span reactions → `reactionFx`.
     - Set `storyShear = reactionFx` for now.
   - Fill `netArea`, `fx`, `weight`.
   - WX and WY stay zero (A3.2).
3. **`ui/panels/ResultsPanel.tsx`:** for the current Level and `caseId`:
   - **Level forces table:** F_x, weight.
   - **Shear Lines table:** name, position, `reactionFx`.
   - Until B3.2 lands, put a small SX/SY switch at the top of the panel that sets `caseId`.

## Acceptance criteria

- [ ] **T1 SY:** netArea 5000 sf, F_x 26.0 k, weight 120.0 k; reactionFx 5.2 / 13.0 / 7.8
- [ ] **T1 SX:** lines A and B get 13.0 k each
- [ ] **T2:** each Level independently gives 6 / 15 / 9 (SY)
- [ ] The tests go through `analyze()` in `src/engine/analyze.test.ts`, plus `beam.test.ts`
