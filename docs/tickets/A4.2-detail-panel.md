# A4.2 — Detail panel with ρ and Ω₀

- **Track:** A (Hamid)
- **Phase:** A4 (2:00–2:45)
- **Type:** AFK
- **Blocked by:** A3.2

## What to build

1. **Clicking a row** in any Results table sets `selection` (spec §4.3 `Selection`).
2. **`ui/panels/DetailPanel.tsx`** ([spec §5.12](../spec.md#512-ρ-and-ω₀), [§6.5](../spec.md#65-results-panel-and-detail-panel-track-a)). Each view lists all four Load Cases plus the Envelope:
   - **Lateral Element:**
     - seismic: E, ρ·E, 0.7·ρ·E
     - wind: E, 0.6·E (no ρ)
   - **Shear Line:** reactions, story shear, unit shears, and its Collector with E, Ω₀·E, 0.7·Ω₀·E (seismic only).
   - **Transfer:** force, plf, and the transfer Collector with E, Ω₀·E, 0.7·Ω₀·E.
   - **Opening:** size and area.
3. **Factor values:** ρ and Ω₀ come from `project.loads`. Show which values were used.
