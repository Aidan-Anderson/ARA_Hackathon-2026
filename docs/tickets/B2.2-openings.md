# B2.2 — Openings

- **Type:** AFK

## What to build

1. **Opening tool:** drag a rectangle on the plan, snapping to 1 ft (or Gridlines in Grid mode). It adds an `Opening` to the current Level.
2. **Drawing:** Openings are hatched, above the outline fill and below the Shear Lines.
3. **Select an Opening** (click) → `selection = { kind: 'opening', … }`, highlighted. The Delete tool removes it.
4. **Clipping:** an Opening dragged partly outside the outline is clipped to the outline's bounding box. The engine handles the rest.
