## What to build

1. **`src/model/project.ts`, `results.ts`, `ui.ts`:** the types from spec §4.3 and §4.4, as agreed.
2. **`src/model/defaults.ts`:**
   - `newId()` using `crypto.randomUUID()`
   - `createDefaultProject()`, which returns a deep copy of fixture T1
3. **`src/model/geometry.ts`:** `crossSection(outline, direction, position)`.
   - It intersects the line perpendicular to the span axis with the outline and returns `[lo, hi]`, or `null` if the line misses.
   - Example: for a Y-line at x = position, it returns the y-extent.
   - At an outline edge exactly at `position`, return the larger extent of the two sides.
   - Add a unit test for a rectangle and the T3 L-shape (x = 30 → [0, 50]; x = 45 → [0, 25]).
4. **`src/model/fixtures/`:** T1, T1b, T1w, T2, T3, T4, T5, T6 (U outline), and T7 as `Project` objects, exactly per [spec §7.2](../spec.md#72-fixtures-and-expected-values-strength-level-sy-unless-noted). Export them from `fixtures/index.ts`.
5. **`src/engine/analyze.ts` stub:** returns a valid `Results` with all four cases, one `LevelResult` per Level with zeros, and empty arrays. That way the UI compiles before Track A starts.
6. **`App.tsx` skeleton:** state per spec §4.2 and the layout per spec §6.1, using CSS grid. Each placeholder component lives in its owner's folder and just renders its name:
   - `Toolbar` (B)
   - `PlanView` (B)
   - right-hand tabs: `LoadForm` (B), `ResultsPanel` (A), `DetailPanel` (A), `SeismicCodePanel` (A)
   - `Warnings` (A)

   The props follow §4.2.
