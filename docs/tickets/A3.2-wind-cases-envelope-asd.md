# A3.2 — Wind, Load Cases, Envelope, strength/ASD, Warnings bar

- **Track:** A (Hamid)
- **Phase:** A3 (1:15–2:00)
- **Type:** AFK
- **Blocked by:** A3.1

## What to build

1. **Wind cases WX and WY** ([spec §5.3](../spec.md#53-loads-on-a-level-for-one-load-case)):
   - w(s) = windPlf[direction] / 1000 wherever the Level has Diaphragm
   - the F_x and F_px runs are the same; `fpx` is undefined
2. **`asdFactor`:** 0.7 for seismic, 0.6 for wind.
3. **`engine/envelope.ts`** ([spec §5.11](../spec.md#511-load-cases-asd-envelope)):
   - max |value| over the four cases, found **separately** for strength and ASD
   - covers: Lateral Element force, line storyShear, Collector maxForce, span maxUnitShear and maxChord
4. **Results panel:**
   - Strength and ASD columns in every table.
   - Case switch SX / SY / WX / WY / ENV (sets `caseId`).
   - ENV shows the Envelope table with the governing case.
5. **`ui/panels/Warnings.tsx`:** the warnings bar for the current Level. Errors in red, warnings in amber.
