## What to build

1. **Import mode** in the toolbar opens a file picker for PNG, JPG, or PDF ([spec §6.7](../spec.md#67-import-track-b)).
   - **PNG/JPG:** read as a data URL.
   - **PDF:** `npm i pdfjs-dist`. Render **page 1** at 2× scale to a canvas, then to a PNG data URL. Set up the worker with Vite: `import workerUrl from 'pdfjs-dist/build/pdf.worker.min.mjs?url'`.
2. **Calibrate:**
   1. The user clicks two points on the image and types the real distance in ft → `ftPerPx`.
   2. Place the Underlay with its bottom-left at (0, 0).
3. **Adjust:**
   - In Select mode, drag the Underlay to align it.
   - Opacity slider.
   - "Lock" toggle, so it can't be dragged while tracing.
4. **Draw it** as the bottom layer of the current Level. One Underlay per Level; importing again replaces it.

## Acceptance criteria (manual)

- [ ] Import a PNG floor plan, calibrate with a known dimension, and trace the outline in Draw mode. The traced dimensions match the drawing within about 1 ft.
- [ ] Import a PDF and page 1 shows
- [ ] Opacity and Lock work; the Underlay is saved with the project (B4.2)
