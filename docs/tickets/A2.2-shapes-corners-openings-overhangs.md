# A2.2 — L/T shapes, Re-entrant Corners, Openings, Overhangs, validation

- **Track:** A (Hamid)
- **Phase:** A2 (12:30–1:15)
- **Type:** AFK
- **Blocked by:** A2.1

This replaces the "rectangle, no Openings" assumption with the real geometry.

## What to build

1. **`engine/sections.ts`** ([spec §5.2](../spec.md#52-cross-sections-depth-breakpoints)):
   - gross depth d(s), net depth dₙ(s)
   - breakpoints
   - left and right values at jumps
   - netArea
2. **Piecewise loads** in both the F_x and F_px runs, built from those sections.
3. **Re-entrant Corners** ([spec §5.7](../spec.md#57-re-entrant-corners)): `CornerResult` for each inside vertex where the gross depth changes inside a span.
4. **Overhangs** ([spec §5.5](../spec.md#55-diaphragm-spans-and-overhangs-simple-beams)): cantilever spans (`kind: 'overhang'`), plus the `overhang-long` warning above 6 ft.
5. **`src/model/outline.ts`:** `checkOutline(outline)` ([spec §5.13](../spec.md#513-validation)). It checks orthogonal edges, no self-intersection, and that every cut is a single interval.
   - The engine uses it to produce `outline-invalid`, and that Level gets no results.
   - Track B's drawing mode shows its message.
6. **Warnings:** `too-few-lines` (and no spans for that direction), `opening-chords`.
7. **Results panel:** add a **Re-entrant Corners** table (s, point, force).
