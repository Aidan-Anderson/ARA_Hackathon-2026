# B4.2 — Save/load JSON + autosave

- **Track:** B (Aidan)
- **Phase:** B4 (2:00–2:45)
- **Type:** AFK
- **Blocked by:** P0.2

## What to build

1. **`ui/io/saveLoad.ts`** ([spec §6.6](../spec.md#66-save-load-autosave-track-b)):
   - `serializeProject(p)`: pretty-printed JSON
   - `parseProjectFile(text)`: returns a `Project` or an error message. It checks `version === 1`, that `levels` is a non-empty array, and that each Level has `outline`, `shearLines`, `openings`, and `seismic`.
2. **Save** button: downloads `<name>.lateral.json`.
3. **Load** button: file picker → `parseProjectFile`. On error, show the message and keep the current project.
4. **Autosave:**
   - Writes to `localStorage['hackathon2026.project']`, debounced 500 ms.
   - On startup, use the autosave if it's present and valid, otherwise `createDefaultProject()`.
   - If storage is full, save without Underlays and show a one-time notice.
5. **New project** button: confirm, then reset to the default.

## Acceptance criteria

- [ ] **Unit tests:**
  - Every fixture round-trips through `serializeProject` → `parseProjectFile` unchanged.
  - Bad JSON and a wrong version give an error.
- [ ] **Manual:**
  - Save, refresh the page, and the project is still there.
  - Load the saved file and you get the same results.
  - Loading a random JSON file shows an error.
