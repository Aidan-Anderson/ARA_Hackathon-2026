# B4.1 — Levels: add (copy below), picker, delete

- **Track:** B (Aidan)
- **Phase:** B4 (2:00–2:45)
- **Type:** AFK
- **Blocked by:** B1.1

## What to build

1. **Level picker** in the toolbar (`levelId`). The plan, Load form, and results follow the selected Level.
2. **"+ Level":** adds a Level **on top** as a deep copy of the top Level with new ids for everything, named "Level n", and selects it ([spec §6.4](../spec.md#64-load-form-and-levels-track-b)). The Underlay is copied too.
3. **Delete Level** (only if there is more than one); **rename Level**.
4. **Ghost of the Level below:** draw its outline and Shear Lines faintly, so lines can be lined up (and stopped on purpose).

## Acceptance criteria (manual)

- [ ] **Build T2:**
  1. Start from T1 and click "+ Level".
  2. Set the bottom Level to story height 10, F_x 6, weight 40.
  3. Set the top Level to story height 10, F_x 6, weight 20.
  4. After A4.1, the bottom Level's story shear reads 12 / 30 / 18.
- [ ] **Build T5:** delete line 2 on the bottom Level. After A4.1, a transfer Collector appears on the bottom Level at x = 40 with 300 plf.
- [ ] Switching Levels changes the plan and the forms; the ghost of the Level below is visible
