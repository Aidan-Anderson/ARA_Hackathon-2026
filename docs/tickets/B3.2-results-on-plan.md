# B3.2 — Results on the plan, Load Case picker, Strength/ASD

- **Track:** B (Aidan)
- **Phase:** B3 (1:15–2:00)
- **Type:** AFK
- **Blocked by:** B3.1. It draws whatever `results` contains, so diagrams appear as A2.1, A3.1, and A4.1 merge.

## What to build

1. **Toolbar:**
   - Case picker SX / SY / WX / WY / ENV (`caseId`).
   - Strength/ASD toggle (`showAsd`). ASD = value × `asdFactor` of the case.
2. **Results overlay** for the current Level and case ([spec §6.3](../spec.md#63-results-on-the-plan-current-level-and-load-case)):
   - **Shear Lines:** label with the Diaphragm Reaction (F_x) and story shear. Add a "↓ transfer" tag if `continuesBelow` is false.
   - **Lateral Elements:** label with force and plf. Color shows plf relative to the highest on the Level.
   - **Collector diagram** along each line: a filled polygon offset from the line, scaled so the largest is about 8 ft, with the max labeled.
   - **Diaphragm Spans:** the shear and moment diagrams drawn outside the outline along the span axis, plus the max Chord labeled on both Chord edges.
   - **Transfer Collectors** (`transfersIn`): dashed line, labeled with plf and max force.
   - **ENV:** Envelope values with the governing case, e.g. "15.0 k (WY)".
3. **Layer toggles:** labels, Collector diagrams, span diagrams. Keeps the plan readable.
