# B1.1 — Plan view, Grid mode, Shear Lines on Gridlines, Load form

- **Track:** B (Aidan)
- **Phase:** B1 (11:45–12:30)
- **Type:** AFK
- **Blocked by:** P0.2

The walking skeleton for the editor: see the default project on a grid, change
it, and watch the Results panel react.

## What to build

1. **`ui/plan/PlanView.tsx`** ([spec §6.2](../spec.md#62-plan-view)):
   - SVG with a y-flip, so the model stays y-up.
   - Mouse-wheel zoom and drag-to-pan.
   - "Fit" button.
2. **Layers drawn so far:**
   - Gridlines with bubbles (numbers along the bottom, letters on the left)
   - outline fill
   - Shear Lines (dashed, labeled with their name)
   - Lateral Elements (thick, read-only for now)
3. **Grid editor** (in the Loads tab, "Grid" section):
   - X spacings and Y spacings as comma lists (`20, 20, 30, 30`).
   - **"Outline = grid extents"** button sets a rectangle on the current Level.
4. **Toolbar** with Mode (Grid / Draw / Import; only Grid works for now) and Tool (Select / Shear Line; the rest come later).
   - **Shear Line tool in Grid mode:** click a Gridline to add a Shear Line on it.
     - A numbered Gridline gives a Y-line at its x.
     - A lettered Gridline gives an X-line at its y.
     - The line is named after the Gridline.
   - **Default Lateral Element:** the new line gets one Lateral Element over its full length, using `crossSection` (spec §9 item 15).
5. **`ui/panels/LoadForm.tsx`** ([spec §6.4](../spec.md#64-load-form-and-levels-track-b)):
   - building inputs: S_DS, I_e, wind X plf, wind Y plf, ρ, Ω₀
   - current Level inputs: name, story height, F_x psf, seismic weight psf

## Acceptance criteria (manual)

- [ ] On first load, the app shows T1: a 100 × 50 outline, Gridlines, and lines 1, 2, 3, A, B
- [ ] Editing the spacings redraws the Gridlines; "Outline = grid extents" resizes the outline
- [ ] Clicking a Gridline with the Shear Line tool adds a named line, and the Results panel (Track A) gains a row
- [ ] Changing F_x in the Load form changes the reactions in the Results panel
- [ ] Zoom, pan, and Fit work
